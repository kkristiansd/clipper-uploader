Privacy Policy – Clipper Uploader

Last updated: November 18, 2026

Clipper Uploader is a private tool used only by its owner to upload videos to the owner's own YouTube channels through the YouTube API Services.

Data accessed

With the owner's permission (Google OAuth), the tool uses the YouTube Data API to upload videos and to read the name of the signed-in channel. It does not access any other users' data.

Data stored

The OAuth access/refresh token is stored only on the owner's computer, with owner-only file permissions. A local log of the owner's own uploaded video IDs is kept to prevent duplicate uploads. No data is sent to any server other than Google's.

Data sharing

No data is sold, shared or disclosed to third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file also removes stored credentials.

YouTube Terms

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service and the Google Privacy Policy.
