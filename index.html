Clipper Uploader

Clipper Uploader is a private desktop tool used by one independent creator to upload their own edited Short videos to their own YouTube channels. It sets each video's title, description and tags, and schedules its publish time using the YouTube Data API.

It is not available to the public, is not sold, and has no other users.

Uses YouTube API Services. This tool uses the YouTube Data API to upload videos to the owner's YouTube channel. Use of this tool is subject to the YouTube Terms of Service and the Google Privacy Policy.
